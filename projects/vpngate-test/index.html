vpngate-test

VPNGate 节点在线检测 + VLESS 链接转换，单文件 Cloudflare Worker，自带 Web 界面

一句话概括：把「验证 VPNGate 节点还活着吗」这件事从本地 Python 脚本搬进浏览器 —— 粘贴节点或整段 vpngate.csv，Worker 会在 Cloudflare 边缘节点上直接对目标做一次完整 SSTP 握手（TLS → SSTP_DUPLEX_POST → PPP 的 LCP / PAP / IPCP），拿到虚拟 IP 才算有效；挑出有效节点后，一键转成可直接导入 v2rayN / Shadowrocket 的 vless:// 链接。

在线预览 GitHub 仓库 一键部署到 Cloudflare ← 返回项目列表

Cloudflare Workers SSTP / PPP VLESS / WS / XHTTP SSE 流式结果 单文件零依赖 诊断工具 · 学习性质

在线预览：https://vpngate-test.edgeoneai.cc.cd/ —— 打开即用，也可以点上面的按钮部署到自己的 Cloudflare 账号（部署后每次 git push 自动重新部署）。

本工具只做公开数据的连通性检测与格式转换，不提供任何代理服务、不中转任何流量。这是协议研究与学习性质的代码，不做可用性承诺；请遵守所在地法律法规与 Cloudflare 服务条款。

功能

功能说明
解析 / 提取从混乱输入里抠出「主机名/IP:端口」。单行、多行、多种格式混写都支持；自动按 host:port 去重，# 开头的行当注释
SSTP 实测直连节点跑完整建链 + PPP 协商；可选再经隧道做 TCP 三次握手（手搓 IPv4 + TCP 报文与校验和），验证节点真能出网
实时输出SSE 流式推送，逐条刷出成功 / 失败、耗时、分配到的虚拟 IP，带进度条与统计，可随时停止
转 vless 链接批量转换；UUID、ENTRY_HOST、ENTRY_PORT、Host/SNI、TYPE（ws/xhttp）、GLOBAL 六个参数可自定义
HTTP API/api/parse、/api/test（SSE）、/api/convert、/api/config、/healthz，带 CORS
配色切换暖色（默认）/ 暗色一键切换，记在 localStorage

格式示例
主机名:端口vpn228702251.opengw.net:1587

CSV 扫前 5 行找表头：主机列 Hostname/HostName/Host（取不到退回 IP），端口列 TCP_Port/Port/TCP，国家列 Country/CountryLong/CountryShort/Region，速度列 Speed_Mbps/Speed。引号字段按标准 CSV 规则处理。

检测流程

1) TLS 连上节点     connect({ hostname, port }, { secureTransport: 'on' })
                    （节点用自签证书，Cloudflare 出站 TLS 不阻断）

2) SSTP_DUPLEX_POST /sra_{BA195980-CD49-458b-9E23-C84EE0ADCD75}/ HTTP/1.1
   Content-Length: 18446744073709551615            ← 永不结束的请求
   → 回 200 后，这条 TLS 流变成全双工 SSTP 隧道

3) 同一流里发控制报文 MSG_CALL_CONNECT_REQUEST（封装协议 = PPP）
   + 数据报文（载荷 = PPP 帧）

4) PPP 协商：LCP(Configure-Request/Ack) → PAP(vpn/vpn) → IPCP(分配虚拟 IPv4)
   → 拿到 IP 即判定有效

5) 可选：PPP 之上手搓 IPv4 + TCP 报文，对目标完成 SYN → SYN+ACK → ACK

报文格式与 scripts/sstp_check.py、cf-vpngate 完全一致：SSTP 头 4 字节（0x10 | 控制 0x01 / 数据 0x00 | 长度）、数据报文 头 + FF 03 + PPP 帧、控制报文 头 + 消息类型 + 属性数 + 属性。

链接转换

输出的链接与 vpngate 订阅同构，入口固定、出口在 path 里：

vless://{UUID}@{ENTRY_HOST}:{ENTRY_PORT}
  ?encryption=none&security=tls
  &sni={SNI}&fp=chrome&type=ws|xhttp
  &host={SNI}
  &path=/fdip=sstp://vpn:vpn@{节点}:{端口}?ed=2560[&global=1]
  #vpngate.me | {国家} | {短主机名}
参数默认说明
UUID495c7195-…须与服务端一致
ENTRY_HOSTsaas.sin.fan入口地址，域名 / IP 均可
ENTRY_PORT443入口端口
Host / SNIsnip.edgeoneai.cc.cdTLS SNI，同时是请求的 Host
TYPEwsws / xhttp（xhttp 自动补 mode=stream-one、alpn=h2）
GLOBAL不追加三态：不追加 / global=1（强制走落地）/ global=0（不强制）
ed2560Early Data 长度
备注模板vpngate.me | {country} | {name}可用 {country} {name} {host} {port}

转换范围：只生成 VLESS + WebSocket/XHTTP + TLS（security=tls、encryption=none）。不支持 Reality / 非 TLS，也不做 trojan / vmess / ss 与 TCP / gRPC / HTTPUpgrade 转换。

选 xhttp 时，客户端 xhttp 的 extra 必须与服务端一致，否则握手失败或超时。界面上选 xhttp 会自动展开常用 extra（noGRPCHeader / xPadding* / Content-Type: application/octet-stream）供照抄。

HTTP API

# 解析（不联网）
curl -s https://your-host/api/parse -H 'content-type: application/json' \
  -d '{"text":"Japan,vpn798662158.opengw.net,59.136.192.205,834.74,1893","defaultPort":443}'

# 检测（SSE 流式，注意 -N 关闭缓冲）
curl -N -s https://your-host/api/test -H 'content-type: application/json' \
  -d '{"items":[{"host":"vpn228702251.opengw.net","port":1587}],"concurrency":20,"timeout":12}'
#   event: start  → { total, concurrency, timeout }
#   event: result → { host, port, ok, ip, ms, detail }
#   event: warn / error / done

# 转换
curl -s https://your-host/api/convert -H 'content-type: application/json' \
  -d '{"items":[{"host":"vpn228702251.opengw.net","port":1587,"country":"Australia"}],
       "uuid":"11111111-2222-3333-4444-555555555555","entryHost":"1.2.3.4","entryPort":8443,
       "sni":"relay.example.com","type":"xhttp","global":"1"}'

另有 GET /api/config（当前生效配置）与 GET /healthz（健康检查）。全部接口带 Access-Control-Allow-Origin: *。

限制与已知问题

  • Cloudflare 屏蔽部分端口：connect() 连不上 Cloudflare 的屏蔽端口（常见 22 / 23 / 25 / 110 / 143 / 465 / 587 / 993 / 995 / 6667 …）。VPNGate 有不少节点用 995，这类节点在 Worker 上会一律失败，不是节点真的挂了；要测这些端口请用本地 scripts/sstp_check.py。
  • CPU 与时长配额：检测主要是等网络 I/O（不计 CPU），但并发过高仍可能撞上 Worker 的 CPU 上限；整轮默认还有 240s 上限，到点会停止剩余节点并提示。
  • 只测节点本身：不验证「入口 + 节点」整条链路，要测链路需把链接导入客户端实测。
  • 结果不持久化：无数据库 / KV，结果只在当次请求里，刷新即消失，需留存请复制或下载。
  • 转换范围有限：只生成 VLESS + ws/xhttp + TLS 链接，见上文说明。

排障

现象排查
构建报 Can't set compatibility date in the future（10021）compatibility_date 不能晚于当前 UTC 日期。本地时区（UTC+8）比 UTC 早一天，写「今天的本地日期」就会踩；改成已过去的日期并重新部署
全部节点 timeout确认部署正常（/healthz）、端口是否被屏蔽、并发是否过大；可先用本地脚本对照
sstp: http 4xx / pap rejected节点不接受 SSTP，或 PPP 认证被拒（非标准节点）；可改 SSTP_USER / SSTP_PASS
sstp: no ip from ipcp握手走完但没拿到虚拟 IP，多半节点侧会话已满，稍后重试
导入链接连不上依次核对：UUID、ENTRY_HOST/PORT 是否为服务端接入点、SNI 是否匹配；xhttp 还要核对 extra

本地自检

仓库里有三个零依赖脚本（只需 Node，不必装 wrangler）：

npm run check
# = node scripts/check-ui.js     校验内嵌前端各 <script> 块语法
#   && node scripts/check-parse.js  在 Node 里跑解析 / 转换逻辑
#   && node scripts/check-routes.js 冒烟测试 /、/api/parse、/api/convert、/healthz

原理是把 worker.js 里的 Cloudflare 专属 import / export 替换掉后塞进 Node 执行，因此改完代码可以直接回归。
