开源项目

这里收录我维护的几个 Cloudflare Workers 项目：一个解决「对象存储如何用 CDN 加速且零流量成本地读写」，一个是 VLESS 入站 + 多后端落地的协议实验，一个是 VPNGate 节点的自动采集与订阅生成，还有一个是给节点做体检的在线检测与链接转换工具。它们都是单文件、零依赖，可以直接粘贴到 Cloudflare 控制台部署。

cf-b2-worker

Cloudflare Workers ⇄ Backblaze B2 一体化网关。自带 AWS SigV4 实现与网页文件管理器，读写闭环、预签名直传、分片上传；匿名只读 /share/ 公开目录，下载强制经 Worker 不泄露桶信息，回源与出网均走带宽联盟，双向免流量费。

Cloudflare Workers Backblaze B2 S3 SigV4 单文件零依赖
约 1000 行 · 无需 npm 打包 · 密钥不过期

cf-vpngate

VLESS over WebSocket / XHTTP 入站，后端可走 SSTP（VPN Gate 公共节点）、ProxyIP、socks5、http(s) 或 TXT 记录随机落地。SSTP 分支在 Worker 内完成 PPP 协商并手工封装 IPv4/TCP。

VLESS XHTTP SSTP / PPP 协议研究
Worker / Snippets 双形态 · CONFIG 集中配置

vpngate

VPNGate 节点自动采集与订阅生成：每小时抓官方 API 增量入库，每天用 xray 内核逐条实测连通性，只把实测有效的节点输出成 v2rayN / Clash 订阅。

GitHub Actions xray 实测 VLESS / Clash 全自动
原始库 → 有效库 → 订阅 三层流水线，含 20% 有效性安全护栏

vpngate-test

VPNGate 节点在线检测 + VLESS 链接转换。粘贴节点或整段 vpngate.csv，Worker 在 Cloudflare 边缘节点直连做完整 SSTP 握手（LCP / PAP / IPCP）挑出有效节点，再一键转成 vless:// 链接。

Cloudflare Workers SSTP / PPP VLESS / XHTTP 单文件零依赖
SSE 流式结果 · 六个转换参数可自定义 · 在线预览

在线工具

网络测速仪：纯前端的延迟 / 抖动 / 下载 / 上传测速与链路诊断，同样托管在本站，无需安装任何插件。

页面内容随仓库 README 同步更新；部署步骤、参数表与排障清单都写在各自的详情页里。
