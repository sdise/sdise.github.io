vpngate

VPNGate 节点自动采集 + xray 每日实测 + VLESS / Clash 订阅生成，全流程 GitHub Actions 托管

一句话概括：每小时从 VPNGate 官方 API 采集全球志愿者 VPN 中继节点，每天用 xray 内核逐个实测连通性，只把实测有效的节点做成订阅——订阅里没有「可能可用」，只有「刚测过能用」。

数据流水线：原始库 → 有效库 → 订阅

每小时  update.yml   VPNGate API → 增量追加 → vpngate.csv（原始库）
                                              → 重建 vpngate.txt（全量链接）
每天    test.yml     vpngate.txt → xray 逐条实测 → vpngate_tested.csv（有效库）
                                              → 重建 vpngate-v2ray.txt / vpngate-clash.yaml
每周    prune.yml    vpngate_tested.csv 覆盖 vpngate.csv，清除下线节点
  • 每小时更新（每小时第 7 分钟）：只追加新出现的 Hostname，有变化才提交。
  • 每天检测（03:30 UTC）：为每条链接生成最小配置（socks 入站 + vless 出站），经 SOCKS5 请求 https://www.google.com/generate_204，2xx/3xx 视为有效；全程不修改原始库，避免网络波动误删数据。
  • 安全护栏：检测前先确认入口可达；若有效比例低于 20%，判定为系统性故障并自动中止，不写任何文件。
  • 公开仓库的计划任务在 60 天无提交时会被 GitHub 暂停，本项目每小时都有提交，不会触发该限制。

VLESS 链接结构（两段式）

vless://<UUID>@saas.sin.fan:443?encryption=none&security=tls
  &sni=snip.edgeoneai.cc.cd&fp=chrome&alpn=h3,h2&type=ws
  &host=snip.edgeoneai.cc.cd
  &path=/fdip=sstp://vpn:vpn@vpn228702251.opengw.net:1587?ed=2560
  #vpngate.me | Japan | vpn228702251
  1. 入口（固定）：saas.sin.fan:443 —— VLESS + TLS + WebSocket 接入点，SNI/Host 为 snip.edgeoneai.cc.cd，TLS 指纹伪装 chrome。
  2. 出口（每行不同）：path 中的 /fdip=sstp://vpn:vpn@{hostname}:{tcp_port}?ed=2560 —— 入口用 SSTP 协议（账号 vpn/vpn）拨号到对应的 VPNGate 志愿者节点，再把流量桥接回去。

备注格式为 vpngate.me | 国家 | 短主机名，方便在客户端里识别。Clash 版本由 build_clash_proxy 生成同名节点，文件尾部附带 select 类型的 proxy-groups 与 rules: [MATCH, vpngate-手动选择]，因此整个 YAML 就是一份开箱即用的配置。

采集与过滤规则

  1. 跳过 * / # 开头的非数据行，以及列数不足 15 的脏行；
  2. base64 解码第 14 列得到 OpenVPN 配置，正则提取 proto 与 remote 端口；
  3. 只保留同时含 tcp 协议且存在 remote 端口的中继；
  4. 速度换算 Speed(bps) / 1_000_000 → Mbps；
  5. 主机名统一为 <HostName>.opengw.net；同 Hostname 去重，按 Country 升序、Speed 降序排序；
  6. 增量写入：以 Hostname 为键比对原始库，只追加新节点（下线节点由每日检测负责剔除）。

合规说明（GitHub 使用政策评估）

  • Actions 用途：① 定时读取公开 API 并提交数据文件；② 以 xray 作客户端做连通性测试（等价于 CI 集成测试）。
  • 不挖矿、不发送垃圾流量、不对外提供代理服务、不做端口扫描；单次检测约十几分钟、并发适度。
  • 若 GitHub 调整政策或仓库收到警告，应优先降级检测频率（如改为纯 TCP 连通性检测），必要时暂停 test.yml。

风险提示

1. 入口 saas.sin.fan 背后为 Cloudflare 网络，Cloudflare 服务条款 2.2.1(j) 明确禁止未经书面许可「提供 VPN 或类似代理服务」，相关账号存在被封禁风险，请自行评估。

2. 节点由全球志愿者运行，随时上下线，且流量经过第三方节点，不要传输敏感信息。

3. _unregistered_vpn335506854.opengw.net 是全表唯一非标准注册格式的主机名，来源可疑、速度极低（0.99 Mbps），建议不要使用。

4. 各国家/地区对 VPN 的法律规定不同，请遵守当地法律法规。
