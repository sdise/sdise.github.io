开源项目

我维护的几个 Cloudflare Workers 小项目，都是单文件、零依赖，可以直接粘贴到控制台部署。

cf-b2-worker

Cloudflare Workers ⇄ Backblaze B2 一体化网关：自带 AWS SigV4 实现与网页文件管理器，读写闭环、预签名直传、分片上传；匿名只读 /share/，下载强制经 Worker；CF 与 B2 同属带宽联盟，回源与出网双向免流量费。

Workers Backblaze B2 SigV4 零依赖
对比重写了 CF-Proxy-B2 与 cw4b2：去掉 cron 与 CF API Token，读写闭环并默认安全

cf-vpngate

前端 VLESS over WebSocket / XHTTP，后端可走 SSTP（VPN Gate 公共节点）、ProxyIP、socks5、http(s) 或 TXT 记录随机落地；SSTP 分支在 Worker 内完成 PPP 协商并手工封装 IPv4/TCP。

VLESS XHTTP SSTP / PPP 协议研究
按上游 snippet.js 重构：14 个分区、CONFIG 集中配置、DoH 缓存、BYOB 读、上下行攒包与背压

vpngate

VPNGate 节点自动采集与订阅生成：每小时从官方 API 增量入库，每天用 xray 内核逐条实测连通性，只把实测有效的节点输出成 v2rayN / Clash 两种订阅。

Actions xray 实测 订阅生成 全自动
原始库 → 有效库 → 订阅 三层流水线，含 20% 有效性安全护栏

vpngate-test

VPNGate 节点在线检测 + VLESS 链接转换：粘贴节点或 vpngate.csv，在 Cloudflare 边缘节点直连做完整 SSTP 握手（LCP / PAP / IPCP）挑出有效节点，再一键转成 vless:// 链接。

Cloudflare Workers SSTP / PPP VLESS 单文件零依赖
SSE 流式结果 · 六个转换参数可自定义 · 在线预览

另外做了一个 网络测速仪：纯前端的延迟 / 抖动 / 下载 / 上传测速与链路诊断，打开即用。

2026-09-28 Cloudflare Workers SSTP / PPP VLESS

vpngate-test：把 VPNGate 节点检测与 VLESS 链接转换搬进浏览器

把以前要在本地跑 Python 脚本才能做的事 —— 验证 VPNGate 节点还活着吗 —— 做成一个单文件 Cloudflare Worker：粘贴节点（或整段 vpngate.csv），在边缘节点上直连目标做一次完整的 SSTP 握手，把还能用的挑出来，再一键转成可以直接导入 v2rayN / Shadowrocket 的 vless:// 链接。不装任何东西，浏览器打开即用。

它支持主机名:端口 / IP:端口 / IPv6 / sstp:// / vless:// / vpngate.csv / 官方 API CSV / 空格分隔等多种输入，单行多行可混写；检测走 SSE 流式推送，进度与结果逐条刷新；转换时 UUID、ENTRY_HOST、ENTRY_PORT、Host/SNI、TYPE（ws / xhttp）、GLOBAL 六个参数都能自定义。文末还记录了这次踩到的坑：compatibility_date 写成「本地今天」导致的 10021、Cloudflare 屏蔽端口（含 VPNGate 常用的 995）等等。
